# 实验项目：基于 Verilog 的双向 BCD 码秒表设计与实现

本项目设计并实现了一个支持**正计时**与**倒计时**功能的数字秒表系统。整个设计采用模块化的思想，由底层核心计数器 `counter_bcd` 以及顶级控制模块 `stopwatch_basic` 级联组合而成。

---

## 一、 底层核心：4位 BCD 同步加减计数器 (`counter_bcd`)

该模块模仿了经典集成电路 **74LS192** 的行为，是整个秒表的计数基石。它的主要职责是在单个十进制位（0~9）内完成加减，并精准输出进位或借位信号。

### 1. 核心端口与参数
* `RST_VAL`: 参数化设计的复位初始值（默认为 0）。
* `dir`: 方向控制。`0` 为加法（正计时），`1` 为减法（倒计时）。
* `co`: **进位/借位输出脉冲**。它是级联的核心，通过组合逻辑实时计算。

### 2. 核心逻辑讲解
计数器的内部控制遵循严格的**优先级机制**：
$$\text{异步复位 (rst)} > \text{同步置数 (load)} > \text{计数使能 (en)}$$

* **正向计数边界**：当加到 `4'd9` 时，下一个时钟沿回零 `4'd0`，否则正常 `+1`。
* **反向计数边界**：当减到 `4'b0000` ($0$) 时，下一个时钟沿回弹到 `4'd9`，否则正常 `-1`。

> **级联灵魂：`co` 信号的组合逻辑表达式**
> ```verilog
> assign co = en & ((dir == 1'b0 & q == 4'd9) | (dir == 1'b1 & q == 4'd0));
> ```
> * **正计满9进位**：在加法模式下，当前数值为 9 且使能拉高时，`co` 瞬间变高。下一周期自身清零，同时 `co` 作为高位计数器的使能，促使高位 `+1`。
> * **倒计到0借位**：在减法模式下，当前数值为 0 且使能拉高时，`  co` 瞬间变高。下一周期自身变 9，同时促使高位 `-1`。

## 二、 顶层架构：控制与分频网络 (`stopwatch_basic`)

顶级模块负责处理外部输入（时钟、按键、开关），控制整机状态，并例化个位和十位的 BCD 计数器。

### 1. 1Hz 绝对时间基准
由于 FPGA 外部输入时钟 `clk_50M` 为高频的 $50\text{MHz}$，模块内部设计了一个 26 位的分频计数器 `cnt_div`。
* 计数范围：`0` 到 `49_999_999`（共 50,000,000 个周期）。
* 每当计满时，`tick_1hz` 会产生一个持续仅单周期的脉冲。**这个脉冲作为秒表绝对计时的“1秒”齿轮。**

### 2. 状态切换与自动置数
为了让系统在切换模式时能智能化工作，代码引入了**边沿检测**逻辑：
```verilog
reg key2_d1;
always @(posedge clk_50M ...) key2_d1 <= key2;
wire mode_switch_pulse = (key2 ^ key2_d1); // 异或检测变化

```

一旦拨动 `key2` 切换正/倒计时模式，`mode_switch_pulse` 就会触发高电平，从而使能 BCD 计数器的 `load` 信号，实现**自动初始化**：

* 切换到**正计时**（`key2 = 0`）：自动加载初始值 `00`。
* 切换到**倒计时**（`key2 = 1`）：自动加载初始值 `19`。

### 3. 防“过减”死锁逻辑

在倒计时模式下，如果任由计数器无限制减下去，系统会在 `00` 之后突变回 `99`。为了防止这种情况，设计了防过减锁定：

```verilog
wire stop_flag = (key2 == 1'b1) & (q_tens == 4'd0) & (q_ones == 4'd0);
wire run_en = (key2 == 1'b0) ? key0 : (key1 & ~stop_flag);

```

当系统处于倒计时且显示变为 `00` 时，`stop_flag` 立即拉高，**强行切断运行使能 `run_en**`。此时秒表将牢牢锁定在 `00`，即便按下运行键 `key1` 也不会有任何响应。

## 三、 系统级联与整体工作流

模块通过“同源主时钟 + 逐级使能控制”的同步时序方式进行级联：

```
[50MHz 主时钟] ───> 挂载到所有模块的 clk 端 (保持全系统同步)

[1Hz 脉冲驱动] ───> 结合运行控制 ───> [个位 en] 
                                         │
                                   (满9进位/到0借位)
                                         │
                                         v
                                     [十位 en]

```

1. **个位计数器**：由 `tick_1hz` 和运行使能信号联合驱动，每秒改变一次状态。
2. **十位计数器**：个位计数器输出的 `co_ones` 信号直接接在十位的 `en` 端。只有在个位发生 `9->0`（正计）或 `0->9`（倒计）的瞬间，十位才会被唤醒并完成一次加减。
3. **数码管显示**：两组计数器实时输出的 4位 BCD 码（`q_ones` 和 `q_tens`），通过译码器（`SEG7_LUT`）实时转换成段码，驱动硬件数码管显示。

---

## 四、 设计亮点总结

1. **规避时序毛刺**：本设计未将个位的进位信号直接作为十位的“时钟”，而是作为“使能信号”。全系统共用同一个 $50\text{MHz}$ 主时钟，这是标准的**同步时序设计思想**，能极大地避免时钟毛刺和时序违规。
2. **高鲁棒性边界控制**：利用组合逻辑实时截获 `00` 状态并死锁使能，给硬件电路加上了“安全手刹”，保证了倒计时边界的安全可靠。
