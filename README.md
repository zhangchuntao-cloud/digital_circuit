# 基于 Verilog 的双向 BCD 码秒表系统设计说明

本项目设计并实现了一个支持**正计时**与**倒计时**双向切换的数字秒表系统。整个设计采用模块化的数字电路工程思想，通过全同步时序逻辑，将底层核心 BCD 计数器级联，并在顶层加入防过减死锁与自动置数控制。

---

## 一、 底层核心：4位 BCD 同步加减计数器 (`counter_bcd`)

该模块是整个秒表系统的“微观齿轮”，其主要职责是在单个十进制位（`0` 到 `9`）内完成加减，并精准输出进位或借位信号。它的控制逻辑遵循严格的优先级机制：

$$\text{异步复位 (rst)} > \text{同步置数 (load)} > \text{计数使能 (en)}$$

### 1. 边界回环控制

* **正向计数边界**：加到 `4'd9` 时，下一个时钟沿自动回零 `4'd0`，否则正常 `+1`。
* **反向计数边界**：减到 `4'd0` 时，下一个时钟沿自动回弹到 `4'd9`，否则正常 `-1`。

### 2. 级联信号逻辑 (`co`)

进位/借位输出脉冲 `co` 是多位级联的桥梁。它采用**组合逻辑**实时输出，表达式如下：

```verilog
assign co = en & ((dir == 1'b0 & q == 4'd9) | (dir == 1'b1 & q == 4'd0));

```

* **正计满 9 进位**：当 `dir=0` 且计数值为 `9` 时，一旦使能 `en` 有效，`co` 瞬间拉高。下一个主时钟沿到来时，自身清零，同时高位的使能端检测到这个高电平，触发高位 `+1`。
* **倒计到 0 借位**：当 `dir=1` 且计数值为 `0` 时，一旦使能 `en` 有效，`co` 瞬间拉高。下一个主时钟沿到来时，自身跳变回 `9`，同时触发高位 `-1`。

## 二、 顶层架构：控制与分频网络 (`stopwatch_basic`)

顶层模块 [stopwatch_basic.v](https://github.com/zhangchuntao-cloud/digital_circuit/blob/main/PRJ5.srcs/sources_1/new/stopwatch_basic.v) 负责协调外部输入（时钟、按键、开关），控制整机状态，并例化个位和十位的计数器。

### 1. 1Hz 绝对时间基准

由于 FPGA 外部输入时钟 `clk_50M` 为高频的 $50\,\text{MHz}$，模块内部设计了一个 26 位的分频计数器 `cnt_div`。

* 当计数器从 `0` 计满到 `49_999_999` 时（共 50,000,000 个时钟周期），`tick_1hz` 产生一个持续仅单周期的脉冲。**该脉冲作为秒表绝对计时的“1秒”基准线。**

### 2. 状态切换与自动置数

系统通过**异或运算**设计了边沿检测逻辑，用来捕捉模式选择开关 `key2` 的状态变化：

```verilog
wire mode_switch_pulse = (key2 ^ key2_d1);

```

一旦用户切换了正/倒计时模式，`mode_switch_pulse` 就会产生一个同步置数脉冲，命令底层计数器无条件加载各自的模式初值：

* **切换到正计时 (`key2 = 0`)**：十位和个位同步加载，系统自动初始化为 `00`。
* **切换到倒计时 (`key2 = 1`)**：十位加载 `1`，个位加载 `9`，系统自动初始化为 `19`。

### 3. 防“过减”死锁逻辑

在倒计时模式下，如果任由计数器在 `00` 之后继续递减，系统会因为借位错误突变回 `99`。为了防止这一硬件隐患，顶层加入了截获死锁逻辑：

```verilog
wire stop_flag = (key2 == 1'b1) & (q_tens == 4'd0) & (q_ones == 4'd0);
wire run_en = (key2 == 1'b0) ? key0 : (key1 & ~stop_flag);

```

当系统处于倒计时且显示变为 `00` 时，`stop_flag` 立即拉高，**强行切断运行使能 `run_en**`。此时秒表将锁定在 `00`，即便按下运行键也不会继续倒计。

## 三、 系统级联与整体工作流

整个系统基于“同源主时钟 + 逐级使能控制”的标准同步时序电路设计，其数据与控制流向如下：

```
[50MHz 主时钟] ───> 挂载到所有模块的 clk 端 (保持全系统严格同步)

[1Hz 脉冲驱动] ───> 结合运行控制 ───> [个位 en] 
                                         │
                                   (满9进位/到0借位)
                                         │
                                         v
                                     [十位 en]

```

1. **个位计数器**：由 `tick_1hz` 和运行使能信号联合驱动，每秒改变一次状态。
2. **十位计数器**：个位计数器输出的 `co_ones` 信号直接对接十位的 `en` 端。只有在个位发生 `9 -> 0`（正计）或 `0 -> 9`（倒计）的进借位瞬间，十位才会被短促唤醒，完成一次加减。
3. **显示输出**：两组计数器实时输出的 4 位 BCD 码（`q_ones` 和 `q_tens`），通过译码驱动模块（`SEG7_LUT`）转换为七段数码管段码，最终呈现给外部硬件。

## 四、 设计亮点总结

1. **出色的时序鲁棒性**：设计严格规避了“将低位的进位脉冲直接作为高位时钟”的异步时钟级联做法，而是让高低位**共用同源主时钟，利用使能线进行控制**。这种经典的同步设计能极大地消除时钟毛刺，避免硬件在高速运行时产生竞争冒险。
2. **安全边界保护**：利用纯组合逻辑在微观周期内捕获 `00` 状态并瞬间切断驱动使能，给倒计时加上了“电子安全刹车”，保证了系统逻辑在边界状态下的安全与闭环。
